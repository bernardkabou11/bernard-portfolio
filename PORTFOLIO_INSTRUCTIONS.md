# 🧩 Stack technique à utiliser pour générer mon Portfolio

L’IA doit obligatoirement utiliser :

### **Framework**
- **Nuxt 3 ou Nuxt 4**

### **CSS**
- **TailwindCSS**

### **Composants**
- Vue 3 Composition API  
- Composants réutilisables (Navbar, Footer, Hero, ProjectCard, etc.)

### **3D (optionnel mais recommandé)**
- **Three.js**  
- Intégration d’une scène 3D simple (ex : animation, particules, background 3D)

### **Structure du site**
- `/pages/index.vue` → Accueil  
- `/pages/about.vue` → À propos  
- `/pages/projects.vue` → Projets  
- `/pages/contact.vue` → Contact  
- `/components/` → Composants UI  
- `/assets/` → Images, styles  

### **Style attendu**
- Moderne  
- Minimaliste  
- Responsive  
- Animations légères  
- Palette de couleurs harmonieuse (bleu, gris, blanc)
