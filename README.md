## ✨ À propos

Je suis Bernard Daniel Kabou, actuellement en Master 1 Ingénierie du Web à ESGI Rennes, avec une forte appétence pour le développement web moderne, l’architecture logicielle et les solutions performantes.

Je recherche une alternance en développement web et je souhaite contribuer à des projets utiles, bien conçus et orientés utilisateur.

## 📦 Installation

```bash
npm install
```

## 🏃 Démarrage local

```bash
npm run dev -- --host 0.0.0.0
```

Puis ouvrez : http://localhost:3000

## 🏗️ Production

```bash
npm run build
npm run preview -- --host 0.0.0.0
```
